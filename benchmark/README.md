# PlannerGym · пилот на 100 задач

| Категория | Количество | Что делает агент |
|---|---:|---|
| Меблировка | 40 | Расставляет уже имеющиеся предметы |
| Закупка | 30 | Подбирает товары, размещает их и оформляет корзину |
| Техника | 20 | Подбирает технику под нишу, вывод и глубину подключения |
| Сквозной проект | 10 | Выбирает вариант плана, меблирует и оформляет заказ |

В пяти сквозных задачах требуется вариант с переносом перегородки. Каталог синтетический. Размеры в сантиметрах, цены в рублях, сроки в днях. Для каждого эпизода заданы наличие, бюджет и срок. Повторный запуск задачи восстанавливает её начальное состояние.

## Запуск

Нужен Node.js 20+. Установка зависимостей не требуется.

```sh
node benchmark/pilot.mjs verify
node benchmark/pilot.mjs list
node benchmark/pilot.mjs show project-01
node benchmark/pilot.mjs mcp
```

Проверка строит и оценивает допустимое решение для каждой задачи. Разделение по семействам планов даёт 70 задач для обучения, 20 для валидации и 10 для теста. Тестовые задачи доступны в репозитории.

## Подключение агента

Добавьте локальный MCP-сервер с транспортом stdio. Подставьте абсолютный путь к файлу.

```json
{
  "mcpServers": {
    "plannergym": {
      "command": "node",
      "args": ["/path/to/plannergym/benchmark/pilot.mjs", "mcp"]
    }
  }
}
```

1. Вызовите `list_tasks`, затем `select_task` с ID задачи. Он возвращает варианты плана, обязательные предметы, бюджет и срок.
2. Используйте `search_products` и `get_product`. Для оценки стоимости вызовите `quote_cart`. Оформляйте виртуальные покупки через `place_order` и отменяйте через `cancel_order`.
3. Передайте в `evaluate` идентификатор плана в поле `layout` и список `items`. У каждого предмета есть ID требования `id`, `sku`, координаты `x` и `y` от верхнего левого угла соответствующей комнаты и направление лицевой стороны `facing` (`south` или `east`).
4. Получите `passed`, `score`, список ошибок и `reward` за изменение баллов с прошлой оценки. Для нового эпизода снова вызовите `select_task`.

В оцениваемом плане проверяются границы комнаты, свободная полоса от двери, пересечения предметов и зон открывания, ниши с выводами, стоимость, срок и соответствие заказов размещённым предметам. При соблюдении обязательных условий начисляется 80 баллов и до 20 дополнительных баллов за качество. Проход и зоны открывания заданы геометрией задачи. Сетевой каталог и реальные платежи в пилоте отсутствуют.

Для агента на JavaScript тот же интерфейс доступен через экспорт `listTasks` и `selectTask` из `pilot.mjs`. Каждый вызов `selectTask` создаёт отдельное состояние эпизода.
